# 2023 Samsung AI Challenge - Image Segmentation

**Samsung, Sep. 2023**

Semantic segmentation with run-length-encoded (RLE) masks.

## Approach
- Built a U-Net segmentation pipeline with RLE encoding/decoding for submission.
- Modified the provided baseline model and compared it against the U-Net pipeline.

## Files
- `Run Length Encoding U-Net Segmentation.ipynb`: U-Net with RLE masks
- `Baseline RLE Encode Model 변경.ipynb`: Modified baseline
